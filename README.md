# Magic Recipe: Logical ✦

> 日常の食材を、エンジニアリングの視点と少しの魔法で「論理的に錬成」する不思議な献立帖。

---

## 概要

このアプリは、入力された材料を「データ」として解釈し、独自のアルゴリズムによって「不思議な作り方」を構築します。外部 API に依存せず、クライアントサイドの定数と論理のみで、数百万通りの体験を迅速に提供します。

**「静謐な佇まいの中に、緻密な論理が息づく」**
そんな、言葉の調和を形にしました。

---

## 特徴

### Zero API Cost
1,000 個超の厳選されたワード配列により、完全無料で永続的なユーモアを提供。サーバー不要・通信コストゼロ。

### Minimalist UI
視覚的なノイズとなるアニメーションを排除。タイポグラフィの美しさと配置にこだわった、目に優しいインターフェース。

### Clean Experience
ネガティブな表現を一切含まず、他人の PC や共有環境でも安心して利用できるクリーンな設計。

### Logical Narrative
システムエンジニアリングのメタファーを用いた、知的でシュールなレシピ構成。

---

## 錬成プロセス（Magic Logic）

入力された材料は、以下の 3 段階のライフサイクルを経てレシピ化されます。

```
[ Initialization ]
  材料をインスタンスとして生成し、
  仮想メモリ上で依存関係を解決。

        ↓

[ Computation ]
  各要素の特性を並列処理し、
  味覚の競合を回避しながら論理的な熱を付与。

        ↓

[ Deployment ]
  緻密に計算された配置を試み、
  本番環境（あなたの食卓）へ反映。
```

---

## 使い方

1. 材料をいくつか入力します（例：いちご　生クリーム　醤油）。
2. **「Cast（詠唱）」** ボタンを静かに押します。
3. 出力された論理的な工程を読み、その不思議な調和を楽しみます。
4. 必要に応じて「ビルド成功ログ」を SNS へ共有してください。

---

## ローカル環境での起動

```bash
# リポジトリをクローン
git clone <repository-url>
cd magic-recipe-logical

# 依存パッケージをインストール（公式 npm レジストリのみ使用）
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで `http://localhost:5173` を開くと起動します。

### ビルド

```bash
npm run build      # 本番用ビルド
npm run preview    # ビルド結果のプレビュー
```

## ディレクトリ構成（予定）

```
src/
├── components/    # UI コンポーネント
├── data/          # 1,000 語超のワード配列（定数）

```

## 注意事項

- 本アプリは空腹を物理的に満たすものではなく、精神的な充足を目的としています。
- 生成されるレシピは型安全ですが、実際の味の再現性については「未定義」とさせていただきます。
- 盛り付けの配置には意図がありますが、環境により多少の差異が生じる場合があります。
